# Leaf Lite

A tiny viewer that opens almost any document without the weight.

## Supported formats

- PDF & Word documents
- Excel spreadsheets
- Plain text & Markdown

## Design rules

One accent colour, three type sizes, no chrome that isn't earning its place.

1. Everything renders offline.
2. Nothing is uploaded, tracked or shared.
3. The APK stays small enough for a 2015 phone.

### Inline formatting

**Bold text**, *italic text*, ***both***, `inline code` and a
[link to nothing](https://example.com).

> Documents should open instantly.
> That is the whole product.
